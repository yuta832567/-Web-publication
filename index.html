SECURITY
🚨 公開前に必ず確認 — セキュリティの落とし穴

AIで作ったコードをそのまま公開すると、意図せず重大な事故につながることがあります。以下を必ず読んでから公開してください。

🔑 最大の落とし穴：APIキーの漏洩

AIが生成したコードにAPIキー（OpenAI・Google Maps等の認証パスワード）が直接書かれていることがあります。 そのままGitHubに公開すると全世界から閲覧可能になり、第三者に悪用されて高額請求が発生する実例が報告されています。

❌ やってはいけない例

コード内にAPIキーを直接記述して、そのままGitHubに公開する。

const API_KEY = "sk-abc123..." ← 危険！
✅ 正しいやり方

環境変数（.envファイル）に保存し、.gitignoreでGit管理から除外する。

.envファイル: API_KEY=sk-abc123...
.gitignore: .env ← これで公開されない
AI生成コードの品質チェックリスト

AIが作ったコードを公開する前に、以下を確認してください。

⚠️APIキー・パスワードがコードに直接書かれていないか
⚠️.envファイルが.gitignoreに含まれているか
⚠️GitHubリポジトリが意図せず「Public」になっていないか
✅スマホ画面で表示が崩れていないか（レスポンシブ確認）
✅リンクやボタンが正しく動作するか
✅不要なconsole.logやテスト用データが残っていないか
✅ページタイトル・OGP画像が設定されているか（SNS共有時に影響）
✅表示速度は十分か（画像サイズが大きすぎないか）
TROUBLESHOOTING
初心者がぶつかる3大トラブル

公開後に「あれ？」となりやすいトラブルと対処法です。

❌ ビルドが失敗する

原因：パッケージの不足、Node.jsのバージョン違い、タイプエラーなど。
対処：エラーログを読み、AIに「このエラーを直して」と貼り付ける。Vercel/Netlifyの管理画面でNode.jsバージョンを指定する。

❌ 404エラーが出る

原因：ファイル名のミス、ルーティング設定の不備、index.htmlがない。
対処：ファイル名を確認（大文字小文字は区別される）。Next.jsの場合はpagesフォルダの構造を確認。

❌ 画面が真っ白

原因：JavaScriptエラーでレンダリングが停止している。コンソールにエラーが出ている。
対処：ブラウザの開発者ツール（F12）→Consoleタブでエラーを確認し、AIにエラー内容を見せる。

FAQ
よくある疑問を先回り解消

クリックすると答えが開きます。

🤔VercelとNetlify、どっちを使えばいい？
▼
Next.jsならVercel、HTMLやAstroのLPならNetlifyが最適。VercelはNext.js開発元で機能を最大限活かせます。NetlifyはHTMLをドラッグ&ドロップで公開でき簡単です。
🤔Next.jsとAstro、どちらで作ればいい？
▼
ページ中心（LP・ブログ）ならAstro、動的機能があるアプリならNext.js。AIがNext.jsでコードを出力した場合はそのままNext.jsを使うのが最も効率的です。
🤔無料で公開できますか？費用はどれくらい？
▼
最初は無料で公開できます。Vercel・Netlify・Cloudflare Pagesはいずれも個人利用は無料です。アクセスが増えたり商用利用すると有料プラン（月数千円〜）が必要になります。まずは無料枠で始めましょう。
🤔AIが作ったコードをそのまま公開できますか？
▼
多くの場合はできますが確認が必要です。HTML一枚→Netlifyにドラッグ。Next.js→GitHub＋Vercel連携。ただしAPIキーが含まれている場合は環境変数に隠す必要があります。「セキュリティ・注意点」タブを必ず確認してください。
🤔WordPressは今でも使うべき？
▼
用途によります。ブログ・お知らせ・コーポレートサイトは引き続きWordPressが有力です。AIツールやLPの公開にはNext.js+VercelやNetlifyの方が向いています。両方を並行運用するのがおすすめです。
🤔Codex・Claude Code・Antigravity、初心者はどれ？
▼
迷ったらCodexから。ChatGPTと同じアカウントで使えるため新しいサービスに慣れる手間が最も少ないです。3つのできることはほぼ同じ。まずCodexを試して、必要を感じたら他を使い分けましょう。
🤔AIに全部任せても大丈夫？
▼
「一緒に進める」が正解です。AIは間違えます。特にファイル削除・外部接続・本番反映は必ず人間が確認。AIは「速くする道具」であり「最終判断をする道具」ではありません。
🤔ノーコード（Bubble等）とコード系はどちらがいい？
▼
目的次第です。マウスだけで完結させたい→ノーコード（Bubble/Glide）。AIにコードを書いてもらって自由に作りたい→コード系（Next.js+Vercel等）。社内の試作品にはノーコード、本番サービスにはコード系が向く傾向があります。

CONCLUSION
一言まとめ

WordPress（ワードプレス）

→会社サイト・ブログ管理

Netlify / Cloudflare（ネットリファイ／クラウドフレア）

→LP・HTMLツール公開

Vercel（ヴァーセル）

→Next.js・React系アプリ

Supabase / Firebase（スーパーベース／ファイヤーベース）

→ログイン・DB・ユーザー情報

Next.js / Astro（ネクスト／アストロ）

→万能フレームワーク / 軽量型

Codex（コーデックス）

→初心者向けAIエージェント

Claude Code（クロード コード）

→ターミナル派向けエージェント

Antigravity（アンチグラビティ）

→Web/UI検証・Google系

Bubble / Glide（バブル／グライド）

→ノーコードでMVP・社内ツール

最初の判断はこの一言で

LP・紹介ページ → HTML or Astro ＋ Netlify / Cloudflare
AIアプリ・ツール → Next.js ＋ Vercel
ログイン・データ保存あり → Next.js ＋ Supabase → Vercel
AIエージェント → 迷ったらCodex。ターミナル派はClaude Code
コード不要がいい → Bubble / Glide
